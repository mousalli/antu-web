## Publicación
1. Descomprime el ZIP.
2. En Cloudflare Pages abre el proyecto.
3. Ve a Deployments > Create deployment.
4. Arrastra todos los archivos y carpetas.
5. Publica y actualiza con Ctrl+F5.
